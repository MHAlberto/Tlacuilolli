# Changelog

## 0.4.0

- Give mathematical statements and the text following display equations more vertical space.
- Add `equation` for numbered displays and native cross-references.
- Add an English PDF manual with Typst listings and rendered examples for every public macro.

## 0.3.0

- Add syntax highlighting and line numbers to fenced code blocks.
- Add `code-listing` for optional titles and custom line numbering.
- Add a code example with six programming languages and a dedicated references page.

## 0.0.2 · GitHub release

- Use New Computer Modern as the default text face and reduce the display equation size.
- Add options for the display equation size and the title font.
- Add a visual quick start with page previews and complete example PDFs.

## 0.1.0 · Initial Typst Universe submission

- Add a serif document style with configurable type, US Letter and A4 layouts, and optional metadata and page numbering.
- Add native figure layouts, scholarly tables, Roman lists, display equations, and bilingual mathematical environments with document-wide counters.
- Include Spanish physics and English mathematics and literature examples, local installation instructions, and compilation tests.
- Add PDF subject and keyword options, content-sized tables, and reproducible TikZ sources for the physics and mathematics diagrams.
- Use the same US Letter layout across the examples and paginate bibliographies separately.
- Name the package Tlacuilolli and add project-local skills for TikZ figures and image optimization.
